# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private vulnerability
reporting instead: in this repository, *Security › Report a vulnerability*.

Include the plugin and GLPI versions, the steps to reproduce and the impact you observed. You will get
an answer as soon as possible; once a fix is released, the report is credited in the changelog unless
you prefer otherwise.
